Cкрипт для пакетного анализа данных о заказах интернет-магазина в Python с использованием библиотеки Pandas. 
Датасет с сайта Kaggle: Synthetic Order Records: 10K to 100K Records (лицензия CC BY 4.0, разрешено использование в учебных целях)
Данные находятся в нескольких CSV-файлах в папке data/, один из файлов намеренно с ошибкой. Скрипт должен обработать все файлы в папке, рассчитать метрики по каждому файлу и сохранить общий результат, а также отработать ошибки и сохранить отчет  о них в log.
